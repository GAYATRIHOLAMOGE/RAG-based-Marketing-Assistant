# RAG-based Marketing Assistant

A fully local, privacy-first chatbot that answers questions from a brand's product catalog and press releases using **Retrieval-Augmented Generation (RAG)**. No API keys required — everything runs on your machine.

---

## Tech Stack

| Component | Tool |
|---|---|
| LLM | Mistral 7B via [Ollama](https://ollama.com) |
| Embeddings | `all-MiniLM-L6-v2` (sentence-transformers) |
| Vector Database | ChromaDB |
| RAG Framework | LangChain |
| UI | Streamlit |

---

## Project Structure

```
Rag based Chatbot/
├── data/
│   ├── product_catalog.txt    ← Product data (prices, features, specs)
│   └── press_releases.txt     ← Brand news and announcements
├── chroma_db/                 ← Vector store (auto-generated by ingest.py)
├── app.py                     ← Streamlit chatbot UI
├── ingest.py                  ← Document ingestion pipeline
└── requirements.txt
```

## Prerequisites

### 1. Python 3.9+
Make sure Python is installed: `python --version`

### 2. Ollama + Mistral
1. Download and install Ollama from [https://ollama.com](https://ollama.com)
2. Pull the Mistral model (one-time, ~3.8 GB):
   ```powershell
   ollama pull mistral
   ```
3. Ollama runs as a background service automatically after installation.

## Setup & Installation

**1. Create and activate a virtual environment**
```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
```

**2. Install dependencies**
```powershell
pip install -r requirements.txt
```

**3. Build the vector store**
```powershell
python ingest.py
```

**4. Start the chatbot**
```powershell
streamlit run app.py
```

Open your browser at **http://localhost:8501**

## How It Works

```
User Question
     │
     ▼
Embed question  ──►  ChromaDB  ──►  Top-K relevant chunks
                                           │
                                           ▼
                               Mistral 7B (via Ollama)
                                           │
                                           ▼
                                    Grounded Answer
```

1. **Ingest** — documents in `./data` are split into 500-token chunks, embedded with `all-MiniLM-L6-v2`, and stored in ChromaDB.
2. **Retrieve** — at query time, the top-4 most relevant chunks are fetched using MMR (Maximal Marginal Relevance) search.
3. **Generate** — Mistral 7B receives the retrieved context + conversation history and generates a grounded answer.
4. **Memory** — the last 5 conversation turns are kept in memory for follow-up questions.

## Using Your Own Data

1. Replace or add files in the `./data` folder (`.txt`, `.pdf`, or `.docx` supported).
2. Update the brand name and support details in the `SYSTEM_PROMPT` inside `app.py`.
3. Re-run ingestion:
   ```powershell
   python ingest.py
   ```
4. Restart the app:
   ```powershell
   streamlit run app.py
   ```

### Supported file formats

| Format | Works out of the box |
|---|---|
| `.txt` | Yes (default) |
| `.pdf` | Yes — change glob in `ingest.py` to `**/*.pdf` |
| `.docx` | Yes — change glob in `ingest.py` to `**/*.docx` |

## Configuration

Key constants at the top of each file:

**`ingest.py`**
| Variable | Default | Description |
|---|---|---|
| `DATA_DIR` | `./data` | Folder containing source documents |
| `CHROMA_DIR` | `./chroma_db` | Where the vector store is saved |
| `EMBED_MODEL` | `all-MiniLM-L6-v2` | HuggingFace embedding model |
| `CHUNK_SIZE` | `500` | Tokens per chunk |
| `CHUNK_OVERLAP` | `100` | Overlap between chunks |

**`app.py`**
| Variable | Default | Description |
|---|---|---|
| `OLLAMA_MODEL` | `mistral` | Local LLM model name |
| `TOP_K` | `4` | Number of chunks retrieved per query |

## Troubleshooting

**"Vector store not found"**
→ Run `python ingest.py` first.

**Ollama connection error in the UI**
→ Make sure Ollama is running: `ollama serve`

**Slow first response**
→ Normal — the embedding model and LLM load into memory on the first query. Subsequent queries are faster.

**Want a different LLM?**
→ Pull any Ollama model and update `OLLAMA_MODEL` in `app.py`:
```powershell
ollama pull llama3        # Meta Llama 3 8B
ollama pull gemma3        # Google Gemma 3
ollama pull phi4          # Microsoft Phi-4
```
